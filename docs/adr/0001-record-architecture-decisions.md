# 1. Record architecture decisions

Date: 2026

## Status

Accepted

## Context

We need to remember why significant technical decisions were made, including the options we rejected.

## Decision

We record each significant decision as a short Architecture Decision Record in `docs/adr/`, numbered in order.

## Consequences

Newcomers can read the history of the architecture. A decision is changed by a new ADR that supersedes the old one.
